# Tarefas

MVP funcional de um organizador pessoal inspirado na lógica visual do Google Calendar.

## Como usar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. As tarefas ficam salvas no `localStorage` do navegador.

## Incluído
- Hoje, Semana, Calendário e Estatísticas
- Criar, editar, excluir, duplicar e concluir tarefas
- 8 categorias
- Data, horário opcional e duração
- Eventos no calendário
- Progresso diário
- Filtro por categoria
- Perfil e tema claro/escuro/sistema
- Calendário mensal com duplo clique no dia para criar tarefa

## Próxima etapa para produção
Para login real, sincronização entre dispositivos, senha segura, notificações e banco de dados, conectar um backend (ex.: Supabase/Firebase) e transformar a interface em uma aplicação React/Next.js ou PWA.
